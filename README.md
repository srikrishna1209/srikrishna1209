# 🚀 Featured Projects

## 🔎 FindLost – College Lost & Found Portal

A full-stack college **Lost & Found Portal** that helps students report, search, and recover lost items through a centralized web application.

### ✨ Features

- 📌 Report lost and found items
- 🔎 Search and browse lost/found items
- 👤 User registration and login
- 🔐 JWT authentication and role-based access
- 🖼️ Cloudinary image uploads
- 📋 Track reported items
- 📩 Claim request management
- 👨‍💼 Admin dashboard
- 🛡️ Admin management of items, claims and contact messages
- 📱 Responsive web interface
- ☁️ Cloud deployment

### 🛠️ Tech Stack

```text
Frontend
React.js + Vite
        ↓
Backend
Java + Spring Boot REST API
        ↓
Security
JWT + Role-Based Access
        ↓
Data Access
Spring Data JPA + Hibernate
        ↓
Database
PostgreSQL
        ↓
Image Storage
Cloudinary
        ↓
Deployment
Vercel + Render + Neon PostgreSQL
```
